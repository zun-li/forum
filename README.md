# Forum

## 项目简介

Forum 是一个用 Go（Gin、GORM）和 Vue 3 构建的社区论坛。Go 服务内嵌前端页面，网页和 API 共用一个端口。

欢迎[在线体验论坛](http://124.223.8.208/)。你可以直接浏览帖子，也可以登录后发帖、留言或投票。

## 功能介绍

- **访客**
  - 浏览全站或单个频道的帖子，按发布时间（New）或热度（Score）排序。
  - 打开帖子阅读正文，也可以点击首页的留言数直接进入讨论区。
- **用户**
  - 选择频道发帖，在帖子下留言，也可以删除自己发表的帖子或留言。
  - 在帖子发表后七天内投赞成票、反对票，或撤回自己的投票。
  - 在账号菜单中修改用户名或密码。
- **管理员**
  - 首次使用 `admin` 和初始密码 `666666` 登录，按提示改密后用新密码重新登录。
  - 在首页「社区频道」中选择「新建频道」，填写频道名称和简介。
  - 在帖子详情页删除任意帖子或留言。

## 快速开始

### 1. 生成密钥（仅首次运行）

在项目根目录用 OpenSSL 生成数据库密码和 JWT 密钥，保存到 `.env`。已有 `.env` 时可跳过这一步。

```sh
if [ ! -e .env ]; then
  (umask 077; printf 'DB_PASSWORD=%s\nJWT_SECRET=%s\n' \
    "$(openssl rand -hex 24)" "$(openssl rand -hex 32)" > .env)
fi
```

### 2. 启动论坛

在项目根目录运行 Docker Compose，启动数据库、Redis 和论坛服务。

```sh
docker compose up -d --build --wait
```

启动后即可打开[论坛首页](http://127.0.0.1:8080)。

## 项目结构

```text
├── cmd/forum/     Go 服务入口
├── config/        默认配置
├── internal/      用户、会话、频道、帖子、投票及 API 路由
├── pkg/           ID 生成、密码哈希和 JWT 工具
└── web/           Vue 源码和嵌入 Go 服务的静态资源
```

## 核心流程

- **服务启动** — 连接 MySQL 和 Redis，补建缺失的数据表，初始化默认频道和管理员账号。补全帖子排行索引后，服务开始接收请求。
- **注册与登录** — 注册时用 Argon2id 对密码做哈希，再将账号写入 MySQL。登录验密后签发 JWT，并在 Redis 中记录会话。再次登录会替换旧会话，退出登录会撤销当前会话。
- **发布帖子** — 服务确认频道存在后生成帖子 ID，将正文写入 MySQL，再把 ID 加入 Redis 的全站和频道排行榜。
- **浏览帖子** — 首页按频道和排序方式从 Redis 取得一页帖子 ID，再从 MySQL 批量读取帖子、作者和留言数，按榜单顺序展示。
- **投票与排名** — Redis 比较用户的新旧投票，在同一次操作中保存投票结果并调整全站和频道热度。改票和撤票都只计算差额。
- **发表与阅读留言** — 服务在 MySQL 事务中确认帖子仍可见，再保存留言。详情页先加载最近 20 条，读者可以继续向前翻阅。
- **删除内容** — 服务校验作者身份或管理员权限。删除留言会移除该条记录。删除帖子会将其标记为已删除，从排行榜移除，并隐藏该帖下的所有留言。
